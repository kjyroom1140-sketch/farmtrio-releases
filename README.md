# FarmTrio Android 다운로드

[최신 APK 다운로드](https://github.com/kjyroom1140-sketch/farmtrio-releases/releases/latest/download/FarmTrio.apk) · [버전별 변경 내용](https://github.com/kjyroom1140-sketch/farmtrio-releases/releases) · [FarmTrio 로그인](https://farmtrio.com/farm/login)

이 저장소는 **Android 테스트 앱의 설치 파일 배포 전용**입니다. 소스 코드, 개인정보, 서버 설정과 서명 개인키는 포함하지 않습니다. 테스트 배포이며 정식 스토어 배포가 아닙니다.

## 설치 / 업데이트

1. 휴대전화에서 최신 APK를 다운로드합니다.
2. 다운로드한 파일을 열고 Android 설치 안내에 따라 승인합니다. 필요한 경우 다운로드에 사용한 브라우저 또는 파일 앱의 설치 권한을 허용합니다.
3. 기존 FarmTrio가 설치되어 있으면 삭제하지 않고 업데이트합니다.

최신 버전 정보는 릴리스의 `update.json`에 있습니다. 앱 홈의 자동 버전 확인과 설정의 **업데이트 확인**은 이 정보를 이용합니다. 앱/계정/농장 접근 권한은 FarmTrio 서버에서 별도로 검사합니다.

`FarmTrio.apk`는 설치 파일이고 GitHub가 자동으로 제공하는 `Source code (zip/tar.gz)`는 설치 파일이 아닙니다.
