# FarmTrio 새 Flutter 앱 개발 중

FarmTrio는 농장 관리자·직원이 사용하는 Android·iPhone 공통 Flutter/Dart 앱으로 개발 중입니다.

**현재 제공하는 설치 파일은 없습니다.** 기존 Capacitor Android 앱의 공개 APK와 업데이트 메타데이터는 모두 삭제했습니다. 구버전 파일을 새 앱으로 설치하거나 안내하지 마세요.

새 앱은 실제 농장 업무, Android/iPhone 기기, QR·카메라·푸시·서명 검증과 배포 준비가 끝난 뒤 별도로 공개합니다. 현재 상태는 정식 출시 완료가 아닙니다.

[FarmTrio 홈페이지](https://farmtrio.com/farm/login)

이 저장소에는 앱 소스·Firebase 설정·서명키·서버 자격정보를 게시하지 않습니다.
